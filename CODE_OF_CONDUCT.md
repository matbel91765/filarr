# Code of Conduct

## Our pledge

We want Filarr to be a place where anyone can ask questions, file bugs and propose changes without being talked down to. That requires a baseline of respect from everyone — maintainers and contributors alike.

## Expected behaviour

- Be patient with people learning the codebase.
- Assume good faith. Ask before accusing.
- Critique code, not people. "This function does X which breaks Y" is fine. "You clearly don't understand X" is not.
- Stay on topic. Issues and PRs are not the place for unrelated political or personal arguments.
- When you disagree, say so plainly and propose a concrete alternative.

## Unacceptable behaviour

- Harassment, intimidation or personal attacks of any kind.
- Discriminatory language or jokes — race, gender, sexuality, religion, nationality, disability, anything along those lines.
- Posting other people's private information without consent.
- Sustained derailing of issue threads.
- Repeated bad-faith arguments after being asked to stop.

## Scope

This applies to every project space: issues, pull requests, discussions, commit messages, the wiki, and any other channel a maintainer is expected to read in their capacity as a maintainer.

## Enforcement

Reports go to **contact@filarr.com**. Include links and screenshots if possible. Reports are kept private. Maintainers may, at their discretion, edit or delete offending content, lock threads, and block accounts that ignore warnings.

A first incident usually results in a private note. Repeated or severe incidents result in a permanent ban.

## Attribution

This Code of Conduct draws on the spirit of the Contributor Covenant 2.1 and the LLVM Project Code of Conduct, condensed for a small project.
